# ADE Meter Reading - Android APK

This project wraps the existing web application in a native Android container using Capacitor.

## Build from GitHub Actions

1. Push this project to GitHub.
2. Open the repository's **Actions** tab.
3. Select **Build Android APK**.
4. Press **Run workflow**.
5. When it finishes, download the workflow artifact named **ADE-Meter-Reading-debug**.

The APK is built from the local `index.html` and project assets. No Supabase database is configured here.
